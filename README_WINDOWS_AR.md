# 8×3 — نسخة Windows

هذه نسخة Desktop حقيقية مبنية بـ React + Tauri 2، وليست صفحة Safari/PWA.

## ما يعمل الآن

- ثلاث فترات: نوم → عمل → مهام.
- قفل المرحلة التالية حتى اكتمال مدتها.
- حفظ محلي فوري حتى بدون إنترنت.
- حساب Email/Password عبر Supabase.
- مزامنة تلقائية مع قاعدة البيانات بعد تسجيل الدخول.
- أحدث نسخة بحسب `updatedAt` تفوز عند أول مزامنة بعد الدخول.
- إشعارات Windows Native.
- المؤقت الأصلي محفوظ كـ timestamp، لذلك إعادة فتح التطبيق لا تعيد العد من البداية.
- عند الضغط على X لا يخرج التطبيق؛ يختفي إلى System Tray لكي يستمر فحص المؤقت.
- جدولة التنبيه تحفظ في ملف داخل App Data ويسترجعها التطبيق بعد إعادة تشغيله.
- Dark Mode + RTL + Responsive.

## تجربة سريعة

نسخة المشروع مضبوطة على 30 ثانية لكل مرحلة من خلال `.env` حتى لا تنتظر 8 ساعات أثناء الاختبار.
بعد اعتماد التطبيق، غيّر:

```env
VITE_PHASE_DURATION_MS=28800000
```

## تفعيل الحساب والمزامنة

1. افتح supabase.com وأنشئ مشروعاً مجانياً.
2. افتح SQL Editor وانسخ محتوى `supabase/setup.sql` وشغله مرة واحدة.
3. من Project Settings / API خذ:
   - Project URL
   - Publishable key (أو anon key في المشاريع القديمة)
4. داخل تطبيق 8×3 ستظهر شاشة إعداد التخزين السحابي في قسم الحساب. الصق القيم واضغط حفظ.
5. أنشئ حساباً بالبريد وكلمة المرور.

مفتاح Publishable/anon مصمم للاستخدام داخل تطبيق العميل؛ الحماية الفعلية للصفوف هنا تتم عبر RLS. لا تستخدم Service Role/Secret key داخل التطبيق أبداً.
